# PHP Standards

Status: Draft

## 1. Structure

Prefer clear, function-oriented PHP code with explicit configuration sections.

## 2. Types

Use strict comparisons where appropriate.

Validate external or configuration-derived values before use.

## 3. Errors

Handle expected failures explicitly.

Avoid suppressing errors unless the reason is documented.

## 4. Completeness

For Symcon automation work, prefer complete scripts or complete files over isolated snippets.

## 5. Comments

Comments should explain intent, constraints, or non-obvious behavior.
