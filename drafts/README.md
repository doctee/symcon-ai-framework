# Drafts

This directory contains engineering artifacts that are currently under development and review.

Drafts are not yet normative parts of the framework. They may evolve through multiple review cycles before being moved into their final repository location.

A draft shall still follow the same quality expectations as published SAEF artifacts:

- clear purpose,
- consistent terminology,
- no private installation data,
- explicit rationale for normative recommendations,
- reviewable structure.

Once a draft is accepted, it is moved into its final location within the repository.
