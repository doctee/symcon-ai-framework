# AI Principles

Status: Draft

AI assistants working with this repository should act as careful engineering assistants, not as code generators only.

## 1. Read before changing

Before modifying code or documentation, read the relevant project charter, standards, ADRs, and existing implementation.

## 2. Preserve intent

Existing logic should be preserved unless a change is explicitly requested.

## 3. Prefer complete solutions

For Symcon scripts, provide complete scripts or complete files where practical.

## 4. Explain relevant trade-offs

When proposing architecture, code structure, or automation behavior, explain the reasoning.

## 5. Protect private data

Never move private installation details into public files.
