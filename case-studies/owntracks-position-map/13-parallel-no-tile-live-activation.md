## 2. Controlled Activation

The activation used Symcon MCP only. Its mutation boundary was:

1. prove the new library, module, instance and target directory absent;
2. transfer every generated file into a new private staging directory;
3. verify the complete 21-file inventory and every SHA-256 before an atomic
   rename;
4. load exactly the newly owned local library directory;
5. create and configure one positive, type-verified module instance; and
6. create two positive, type-verified links under the two established parents.

Every bounded MCP result had an empty transport error, an empty PHP execution
error and `truncated=false`.

## 3. Postflight

The read-only postflight proved:

- exactly one active candidate instance;
- exactly three configured OwnTracks sources and one external anchor;
- exactly two new visible links under two distinct existing parents;
- an instance-count delta of one and a link-count delta of two;

No logging function, Archive Control mutation, provider request, routing call,
Connect change, service restart, existing-object reconfiguration, commit or
publication was performed.

## 4. Current Presentation Boundary

The activated candidate is intentionally the provider-free fallback. It has
the borderless local OpenLayers surface, pan/zoom, bounded selected-day reads,
fit-all over complete valid day bounds, selectable path presentation and the
shared hover/tap tooltip. It does not yet have a basemap.

The ETA target remains unconfigured. Consequently, ETA correctly reports an
unavailable state instead of inventing a destination or treating a dynamic
OwnTracks place as the next target. The next functional gate must first define
and privately configure a separately owned WGS84 target resolver. Route-aware
ETA and the optional diagnostic geodesic fallback must remain visually
distinguishable.

## 5. Rollback Boundary

Rollback remains limited to the two new links, the one new candidate instance
and the exact staged library directory after fresh ownership read-back. The
existing map, hook, links, selector behavior, source instances, external
anchor, logging and archives are not rollback targets.
