# Prompt Library

This directory contains reusable engineering prompts for AI assistants working with SAEF.

The prompts are intentionally generic.

Project-specific engineering knowledge belongs into:

- `AGENTS.md`
- `principles/`
- `standards/`
- `knowledge/`
- `references/`

Prompts orchestrate the workflow. Engineering rules belong to the framework documentation.

## Available Prompts

| Prompt | Purpose |
| --- | --- |
| `IMPLEMENT_REFERENCE.md` | Create or extend reference implementations |
| `OPTIMIZE_SCRIPT.md` | General optimization of existing Symcon scripts |
| `OPTIMIZE_CONTROL_SCRIPT.md` | Optimization of automation and control scripts |
| `OPTIMIZE_ANALYSIS_SCRIPT.md` | Optimization of analysis, archive and reporting scripts |
