# Reference Implementations

This directory contains complete, reviewed implementation examples that
demonstrate SAEF engineering practice.

Reference implementations are not snippets. They are intended to show how
principles, standards, engineering knowledge and practical IP-Symcon development
patterns work together.

A reference implementation should include:

- a clear scenario,
- complete code where practical,
- configuration guidance,
- design notes,
- known constraints,
- references to related standards and knowledge articles.

Reference implementations should not contain private installation data.
